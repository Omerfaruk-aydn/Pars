# PARS — Türkçe Programlama Dili

*"Pars gibi hızlı. Türkçe gibi güzel."*

PARS, Python altyapısını kullanan, tamamen Türkçe sözdizimli bir programlama dilidir.

## Hızlı Başlangıç

```bash
pip install pars-turkce-dil
```

```pars
yaz("Merhaba, Dünya!")
```

```bash
pars merhaba.pars
```

## Özellikler

- Tamamen Türkçe sözdizimi
- Python 3.8+ uyumluluğu
- Tüm Python kütüphanelerini destekler
- Türkçe hata mesajları ve ipuçları
- Etkileşimli REPL
- 28 modüllü Türkçe standart kütüphane
- `parskur` (pip yerine) ve `parspy` (python yerine)
- 31 örnek program

## Komutlar

```bash
pars dosya.pars             # PARS dosyası çalıştır
pars -g                    # Etkileşimli mod
pars -cevir dosya.pars      # Python karşılığını göster
pars -kontrol dosya.pars    # Sözdizimi kontrolü
pars derle dosya.pars       # Python'a derle
parskur yükle requests     # Paket yükle (pip yerine)
parspy dosya.py            # Python çalıştır (python yerine)
```
